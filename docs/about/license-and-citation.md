## How to cite

If you use this software in research, please cite the Zenodo record
above. Formatted examples (aligned with Zenodo):

### APA

```text
Narayanan, A., & Raza, S. (2026). AIXeval (Version v0.1.1) [Computer software]. Zenodo.
https://doi.org/10.5281/zenodo.24468828
```

### MLA

```text
Narayanan, A., and S. Raza. AIXeval. Version v0.1.1, Zenodo, 23 Nov. 2026,
https://doi.org/10.5281/zenodo.24468828.
```

### BibTeX

```bibtex
@software{narayanan_raza_2026_aixeval,
  author       = {Narayanan, A. and Raza, S.},
  title        = {AIXeval},
  year         = {2026},
  publisher    = {Zenodo},
  version      = {v0.1.1},
  doi          = {10.5281/zenodo.24468828},
  url          = {https://doi.org/10.5281/zenodo.24468828},
  note         = {Computer software},
  repository   = {https://github.com/VectorInstitute/AIXEval}
}
```

### Related work

For the eight-dimension framing and band policy used on the card, cite
the methodology sources named in [Methodology](../methodology.md),
