# Security

## Report a vulnerability

Email **shaina.raza@vectorinstitute.ai** with a description, the
affected version or commit, and steps to reproduce.

Do **not** open a public GitHub issue for a security report.

Vector AI Engineering acknowledges reports and is the group that
responds. We aim to acknowledge within five business days. This is
not a paid bug-bounty programme.

## Please include

- What the issue allows (data leak, unexpected model call, path
  traversal, …)
- Whether a fixture or a user-supplied dump is required
- Your environment (OS, Python version, `aixeval` version)

## Scope notes

- Uploading a trace to a **hosted** judge is expected behaviour when
  you select that provider. That is not a vulnerability; see
  [Privacy and data](docs/privacy-and-data.md).
- Do not send traces that contain personal or regulated data in a
  vulnerability report unless we have agreed a channel.
